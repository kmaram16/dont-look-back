# Don't Look Back

**EN:** A first-person horror game for Windows (Unity) made by KMM. 4 long levels, 4 monsters: La Sombra, El Osito, El Fantasma and Norberto. Trust no one. No blood or gore — just scares. Game text is in Spanish.

**ES:** Un juego de terror en primera persona para Windows (Unity) hecho por KMM. 4 niveles largos, 4 monstruos: La Sombra, El Osito, El Fantasma y Norberto. No confíes en nadie. Sin sangre — solo sustos.

**Download / Descargar:** [Releases](https://github.com/kmaram16/dont-look-back/releases/latest) · https://kmaram16.github.io/arcade/dontlookback/

Controls / Controles: WASD · Mouse · Shift run · Ctrl/C crouch · F flashlight · E use/hide/talk · Space hold breath · Tab objectives · Esc pause. Xbox controller supported.
